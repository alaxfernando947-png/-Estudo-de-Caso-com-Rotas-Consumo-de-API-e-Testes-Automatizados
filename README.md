## 🚀 Sobre o Projeto

Este repositório apresenta um **estudo de caso completo** focado no desenvolvimento de uma aplicação moderna, utilizando tecnologias atuais do ecossistema JavaScript tanto para **web** quanto para **mobile**.

O objetivo é demonstrar, na prática, a construção de uma aplicação **escalável, organizada e responsiva**, aplicando boas práticas e padrões modernos de desenvolvimento.

---

## 📂 Estrutura

```bash

├── 📁 web/
│   ├── src/
│   ├── components/
│   ├── pages/
│   └── assets/
│

│   ├── components/
│   ├── screens/
│   └── assets/


⚙️ Como Rodar
##🌐 Web
cd web
npm install
npm run dev

Acesse: http://localhost:5173

##📱 Mobile
cd mobile
npm install
npx expo start
Escaneie o QR Code
Ou use emulador
